# JSPLAY

专为法系车（标致/雪铁龙）搭载航盛大蓝屏的车机定制适配，提供有线及无线 CarPlay，采用 DiAuto 风格界面。

最棘手的**蓝牙握手**问题耗时近两个月攻关解决；凡尔赛（C5 X）航盛方向盘按键适配也已写入。音频通道和 CarPlay 视频流仍在持续优化，目前 **TCP 走 7000 端口**。欢迎大家一起参与，做出更流畅的端口实现。

> **仓库范围说明：** 离线的认证模块是我们的私有财产，**不包含在本仓库中**。我们只公开方法与接口，供真正懂开发的朋友参考，并据此做出最适合自己的软件。源码中的 `LocalMfiAuthenticationClient` 仅用于演示接口契约，不含任何真实身份或凭据文件；可用的身份需要开发者自行准备。本仓库不提供安装包、签名密钥或配件凭据。

> 本项目专为法系车（标致/雪铁龙）搭载航盛大蓝屏的车机定制适配，重点车型为凡尔赛 C5 X。其他车型未经测试，不在支持范围内，也没有增加品牌适配的计划。

当前构建版本：**JSplayV1.62**（versionCode 62，包名 `com.jsplay.com`）。

公开预览版，未经 Apple 认证。请安装在车机上，而非 iPhone。无需越狱、转接盒或认证服务器。专为 **Android 4.4.3（API 19）航盛大蓝屏车机**适配，也就是法系车标致/雪铁龙（标雪）车机。无线连接使用车机自带热点或同一 WiFi 模式。

- 可选在中控屏显示仪表地图悬浮卡片：拖动位置、双指缩放、点击打开 CarPlay。仪表地图继续显示；需允许显示在其他应用上层。
- 改进地图缩放：放下双指时不再突然改变尺寸，达到最小或最大尺寸后反向缩放立即响应。
- 可选通过网络 ADB 在仪表盘显示歌曲名、歌手及播放或暂停状态。
- CarPlay 导航小组件显示转向、道路、距离、到达信息及歌曲，适用于支持标准 Android 小组件的启动器。
- Android 11 及以上的兼容启动器可选嵌入实时地图，并提供地图宿主及 DiPlay Home 开发示例。地图共享默认关闭。
- CarPlay 跟随比亚迪昼夜模式；已在全屏建立的连接可在摄像头改变窗口大小时保持连接。如果在狭窄的摄像头窗口中连接，窗口扩大后需要重新连接一次。
- 媒体和导航音频通道支持 0–20，并保留旧版保存的导航选择。
- 应用及网站新增乌克兰语；GPS 在方向未知时不再错误地报告向北。

标准导航小组件需要支持 Android 小组件的启动器；比亚迪内置主页不接受任意小组件。悬浮地图和嵌入地图需要启用“CarPlay 仪表地图”。开发示例仅在源代码中提供。

认证使用由本地发布流程注入的实验性配件身份，不是 Apple 官方签发的 MFi 凭据，无法保证未来持续可用。部分车机仍可能卡顿或无法应用图标大小设置。应用界面支持英语、简体中文、阿拉伯语、俄语、乌克兰语和西班牙语。本仓库不提供安装包，请按构建说明从源码自行编译。
